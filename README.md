# Talents for Everyone

The Binding of Isaac: Repentance+ mod (REPENTOGON). Author: blackhellvelz.

English · [Русский](#русский)

An add-on for [Passive Skill Trees](https://steamcommunity.com/sharedfiles/filedetails/?id=3305869734): real character trees for modded characters, and more interesting talents for every vanilla one — not just "+1% to a stat".

### Own trees for modded characters (41 trees)
Each is a full tree of about 110 nodes with five branches built around the character's own mechanics:
- **Fiend Folio** — Fiend, Golem, Inaba, Friend, Slippy, China, Craig, Fend, Frond, Fient, Mi, Freezer Jr., Peat, Classic Fiend, Image, The Skeletal Fiend and tainted Fiend, Golem, Friend, Inaba.
- **Furtherance** — Leah, Peter, Miriam and their tainted versions.
- **Lost and Forgotten** — Robot, Joseph and their tainted versions.
- **IPECAC** — Moses and Tainted Moses.
- **Epiphany** — the tarnished Isaac, Magdalene, Cain, Judas, ???, Samson, Eden, Lost and Keeper.

Without this mod those characters only get the shared tree.

### New talents for vanilla characters
- +20 nodes in the tree of every vanilla and tainted character (34 trees), with mechanics from the character: Azazel's Scapegoat, Bethany's wisps that flare up, ???'s stench cloud, Apollyon's void, and so on.
- +53 nodes in the global tree: hunting, luck, endurance, exploring, tempo.

Every talent has a hand-drawn icon and a description in English and Russian (follows the game language).

### Requirements
- [REPENTOGON](https://steamcommunity.com/sharedfiles/filedetails/?id=3127536138)
- [Passive Skill Trees (Rep+)](https://steamcommunity.com/sharedfiles/filedetails/?id=3305869734)
- for modded trees — the mod of that character (Fiend Folio, Furtherance, Lost and Forgotten, IPECAC, Epiphany); a tree appears only if its character is installed

## Install

Subscribe on Steam Workshop — that's all. To install by hand, copy this folder into `The Binding of Isaac Rebirth/mods/`.

## Repository

This repository is the mod folder itself: `main.lua` is the entry point, the other `.lua` files are its modules, `resources/` — pictures, `metadata.xml` — the Workshop page. Pictures that belong to the game or to other mods are not stored here. Other mods this one works with — [CREDITS.md](CREDITS.md). Code license — [LICENSE](LICENSE) (MIT).

## Русский

Дополнение к [Passive Skill Trees](https://steamcommunity.com/sharedfiles/filedetails/?id=3305869734): настоящие деревья для персонажей модов и интересные таланты для каждого персонажа игры — не только «+1% к характеристике».

### Свои деревья для персонажей модов (41 дерево)
У каждого — полное дерево примерно из 110 узлов, пять веток вокруг его собственных механик:
- **Fiend Folio** — Изверг, Голем, Инаба, Френд, Слиппи, Чайна, Крейг, Фенд, Фронд, Фиент, Ми, Фризер-младшая, Пит, Классический Изверг, Имидж, Скелетный Изверг и порченые Изверг, Голем, Френд, Инаба.
- **Furtherance** — Лия, Пётр, Мириам и их порченые версии.
- **Lost and Forgotten** — Робот, Иосиф и их порченые версии.
- **IPECAC** — Моисей и Порченый Моисей.
- **Epiphany** — потускневшие Исаак, Магдалина, Каин, Иуда, ???, Самсон, Эдем, Потерянный и Хранитель.

Без этого мода у них только общее дерево.

### Новые таланты персонажей игры
- +20 узлов в дереве каждого обычного и порченого персонажа (34 дерева) — с механиками самого персонажа: козёл отпущения Азазеля, вспыхивающие огоньки Вифании, ядовитое облако ???, пустота Аполлиона и т. д.
- +53 узла в общем дереве: охота, удача, стойкость, исследование, темп.

У каждого таланта — рисованный значок и описание на русском и английском (по языку игры).
